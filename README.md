# Wheels of Vic

Static multi-page site, no build step. Serve the folder (python -m http.server 3000, or npx serve -l 3000).

- css/main.css: all styles; colours are the variables on line 1
- js/layout.js: header/footer, loader, page transitions, hero scroll effect, reveal animation
- js/billboard.js: billboard slides (5 second autoplay). Add pictures to images/
- js/stories.js: driver stories (each gets story.html?id=...)
- Pages: index, events, stories, story, music, media, shop, membership
